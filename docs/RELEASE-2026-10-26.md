# October 26 native and source import release

The simplified import flow is deployed at [robyn.academy](https://robyn.academy). Recognised native projects select their Craft and name, check linked files, save and open. Common images, audio and video become reusable source assets without an owning Craft. Existing **Place from studio** controls choose how those originals are used.
