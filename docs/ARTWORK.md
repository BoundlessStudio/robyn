# Original homepage artwork

`public/artwork/offscript-bloom.png` was generated for Robyn using the built-in imagegen tool on October 21, 2026. It depicts a vermilion calla lily with a looping stem, a cobalt tubular vase, and a chrome sphere on warm paper. This is concept artwork for the illustrative OFFSCRIPT campaign, not an output claimed to have been made by the Robyn employee integrations.

The creative prompt asked for an exceptional editorial still-life photograph, a portrait composition, saturated lacquer red and cobalt, directional afternoon light, tactile surfaces and medium-format grain, no lettering or watermark, and a sculptural silhouette. The original generated PNG remains in the Codex generated-images directory. The application uses Next.js responsive image optimization from the local source asset.

The orbit marks, waveform, technical drawing, posters, document studies, and interface compositions are authored SVG, HTML, and CSS. Space Grotesk and Instrument Serif are self-hosted through their Fontsource packages; their distributed license files remain with the packages.
