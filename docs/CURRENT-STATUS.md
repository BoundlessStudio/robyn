# Current pilot status

Updated October 30, 2026. This is the current index; [PLAN.md](PLAN.md) retains the complete scope and dated implementation history. [The review report](PROJECT-REVIEW-2026-10-25.md) tracks remediation and remaining acceptance work.

Robyn is an invitation-only, passwordless, solo-creator studio at **https://robyn.academy**. The authenticated studio is desktop-only. Public signup and commercial subscriptions are disabled. The public homepage supports small screens.

**Deployed and verified: one Robyn with fourteen Craft tools.** Each creator has one visible Robyn and one shared workstation provisioned on demand. Chrome and Brave Search belong to Robyn; existing research notebooks remain editable as Notes. Applications load as skills. Production jobs run one at a time per workspace with immutable task credentials, generation-bound internal profiles and separate work/transfer folders. The primary QA studio is connected to the combined workstation; all seventeen old instances have been retired and deleted. The dated multi-employee records below describe previous deployments.
